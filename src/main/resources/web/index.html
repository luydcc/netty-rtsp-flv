RTSP → FLV 播放测试（Jessibuca）

流状态看板：/streams.html  |  监控统计：/stats  |  播放地址格式：ws://<host>:<port>/live/{streamId}.flv?token=xxx 、http://<host>:<port>/live/{streamId}.flv?token=xxx 、rtsp://<host>:<rtsp.forwardPort>/live/{streamId}?token=xxx
首次播放会在服务端触发一次 RTSP 拉流；多个客户端播放同一 streamId 复用同一条 RTSP（三种协议可混用）。
无客户端观看超过 session.closeDelaySec 秒后自动停止拉流，下次播放重新建流。
